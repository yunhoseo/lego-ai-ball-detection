파이썬 설치하기

처음 한 번만
  1. python.org에 접속해서 노란 Download Python 버튼을 누르고 설치 파일을 실행합니다.
  2. 설치 첫 화면 맨 아래 “Add python.exe to PATH” 체크박스를 반드시 체크하고 Install Now를 누릅니다.
  3. 설치가 끝나면 명령 프롬프트를 엽니다. (⊞ 윈도우 키 → cmd 입력 → Enter)
  4. 아래 명령을 한 줄씩 붙여넣고 Enter. 두 번째 줄은 AI 라이브러리를 내려받느라 몇 분 걸립니다.
> python --version
> pip install ultralytics opencv-python bleak
확인 포인트 — python --version을 쳤을 때 Python 3.11 같은 버전 숫자가 나오면 성공. “내부 또는 외부 명령이 아닙니다”가 나오면 2번의 PATH 체크를 빼먹은 것이니 다시 설치하세요.

폰을 무선 카메라로 만들기

처음 한 번만

Iriun Webcam이라는 무료 앱을 쓰면 폰 카메라 화면이 WiFi를 타고 노트북으로 들어옵니다.

  1. 폰에서: 앱스토어/플레이스토어에서 Iriun Webcam을 설치합니다.
  2. 노트북에서: iriun.com에 접속해 Windows용 프로그램을 내려받아 설치합니다.
  3. 둘 다 실행하면 (같은 WiFi일 때) 자동으로 연결되고, 노트북 Iriun 창에 폰 카메라 화면이 뜹니다.
  4. 폰은 공이 잘 보이는 위치에 거치대로 고정합니다. 실습 중엔 폰 화면이 꺼지지 않게 두세요.
학교 WiFi는 기기끼리 통신을 막아둔 경우가 있어요. 연결이 안 되면 폰의 핫스팟을 켜고 노트북을 그 핫스팟에 연결하면 됩니다.
확인 포인트 — 노트북의 Iriun 창에 폰 카메라 화면이 실시간으로 보이면 성공.

허브에 Pybricks 펌웨어 설치

처음 한 번만

허브 속 운영체제를 파이썬을 알아듣는 Pybricks로 갈아끼우는 단계입니다. 허브마다 딱 한 번만 하면 됩니다.

  1. Chrome(또는 Edge)에서 code.pybricks.com에 접속합니다.
  2. 왼쪽 톱니바퀴(설정) → Install Pybricks Firmware를 누릅니다.
  3. 허브 종류에서 SPIKE Prime을 고르고, 허브 이름은 팀 이름으로 정합니다. (예: HUB-1조)
  4. 화면이 “업데이트 모드로 전환하세요”라고 하면, 아래 순서대로 합니다:
    1. USB를 뽑고 허브 전원을 완전히 끕니다.
    2. 허브의 블루투스 버튼을 누른 채 USB 케이블을 노트북에 꽂습니다.
    3. 불빛이 빨강→초록→파랑 무지개색으로 깜빡일 때까지 계속 누르고 있습니다.
  5. 브라우저 팝업에 LEGO Bootloader 장치가 나타나면 선택 → 연결 → 설치가 진행됩니다.
“호환되는 기기가 없습니다”가 나오면 허브가 아직 업데이트 모드가 아닌 거예요. 4번을 처음부터 다시. 그래도 안 되면 USB 케이블을 다른 것으로 바꿔보세요 (충전 전용 케이블은 데이터가 안 통합니다).
나중에 레고 공식 앱으로 되돌리고 싶으면 같은 설정 메뉴의 Restore Official LEGO Firmware를 누르면 됩니다. 망가지는 것 아니니 걱정 마세요.
확인 포인트 — 설치 진행 바가 100%까지 가고 허브가 다시 켜지면 성공.

허브에 모터 프로그램 넣기

처음 한 번만
  1. 모터를 허브의 A 포트에 꽂습니다. (제일 많이 까먹는 부분!)
  2. code.pybricks.com에서 블루투스 아이콘을 눌러 내 팀 허브에 연결합니다.
  3. 파일 목록 옆 + 버튼으로 새 파일을 만들고, 실습 폴더의 spike_hub_a_once.py 내용을 전부 복사해 붙여넣습니다. (아래에도 전체 코드가 있어요.)
  4. 위쪽 ▶ (실행) 버튼을 누릅니다. 코드가 허브에 저장되면서 바로 실행됩니다.
spike_hub_a_once.py 전체 코드 (펼쳐서 복사) 
from pybricks.hubs import PrimeHub
from pybricks.pupdevices import Motor
from pybricks.parameters import Port, Color
from pybricks.tools import wait

from usys import stdin, stdout
from uselect import poll

hub = PrimeHub()

PORT_A = Port.A

SPIN_SPEED = 500   # 회전 속도 (deg/s)
SPIN_ANGLE = 360   # 1회전

def try_motor(port, name):
    try:
        m = Motor(port)
        print(name, "OK")
        return m
    except Exception:
        print(name, "NOT FOUND")
        return None

def send(msg):
    stdout.buffer.write(msg)

A = try_motor(PORT_A, "A")

keyboard = poll()
keyboard.register(stdin)

hub.light.on(Color.GREEN)
send(b"rdy")

while True:
    if keyboard.poll(0):
        cmd = stdin.buffer.read(1)
        if not cmd:
            continue

        if cmd == b"q":
            break

        if cmd == b"d":
            hub.display.char("d")
            if A is not None:
                A.run_angle(SPIN_SPEED, SPIN_ANGLE)

        send(b"rdy")
    else:
        wait(10)

if A is not None:
    A.stop()
hub.light.on(Color.RED)
hub.display.off()
확인 포인트 — 화면 아래 콘솔에 A OK와 rdy가 찍히면 성공. A NOT FOUND가 나오면 모터 케이블이 A 포트에 안 꽂힌 거예요.

허브 불빛 읽는 법

다음 단계부터는 허브 가운데 버튼의 불빛 색이 지금 뭘 해야 하는지 알려주는 신호등입니다. 이것만 알면 절대 안 헤맵니다.

파란색 깜빡임 — 연결 기다리는 중. 노트북이 허브를 찾을 수 있는 유일한 상태.
초록색 — 프로그램 실행 중. 모터가 신호를 받을 수 있는 상태. 단, 이때는 노트북이 새로 연결할 수 없음.
빨간색 — 프로그램이 끝난 상태. 가운데 버튼을 누르면 다시 시작.
핵심 규칙: 허브는 한 번에 한 곳하고만 연결됩니다. Pybricks 브라우저 탭이 열려 있으면 노트북 프로그램이 허브를 못 찾아요. 실행 전엔 브라우저 탭을 완전히 닫는 것이 규칙입니다.

연습 1 — 카메라 연결 baseline_1_camera.py

폰 카메라 화면을 노트북 창에 띄우는 것이 전부인 코드. 여기서 VIDEO_SOURCE 숫자를 찾아두면 뒤 단계가 편해집니다.

baseline_1_camera.py 전체 코드 
"""
[baseline 1단계] 휴대폰 카메라 연결 테스트

목표: 폰 카메라 화면이 노트북 창에 나오면 성공!
실행 전: Iriun 앱(폰) + Iriun 프로그램(노트북)이 켜져 있어야 합니다.
종료: 카메라 창을 클릭하고 q 키
"""

import sys

import cv2

# 폰 카메라 번호. 내 얼굴(노트북 내장캠)이 나오면 0, 1, 2로 바꿔보세요.
VIDEO_SOURCE = 1

if sys.platform == "darwin":  # 맥에서 테스트할 때용 (Windows는 아래 줄로 실행됨)
    cap = cv2.VideoCapture(VIDEO_SOURCE, cv2.CAP_AVFOUNDATION)
else:
    cap = cv2.VideoCapture(VIDEO_SOURCE)

if not cap.isOpened():
    print("카메라를 열 수 없습니다. VIDEO_SOURCE 숫자를 바꿔서 다시 실행해 보세요.")
    raise SystemExit

print("카메라 열림! 폰 화면이 나오는지 확인하세요. (q = 종료)")

while True:
    ok, frame = cap.read()
    if not ok:
        continue

    cv2.imshow("1. camera test (q=quit)", frame)

    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()
성공 기준 — 창에 폰 카메라 화면이 실시간으로 나온다. (내 얼굴이 나오면 VIDEO_SOURCE를 0, 1, 2로 바꿔가며 재실행)

연습 2 — AI 탐지 baseline_2_vision.py

연습 1에 AI 모델(best.pt)을 얹은 코드. 모터 없이 "AI가 공을 알아보는지"만 확인합니다.

baseline_2_vision.py 전체 코드 
"""
[baseline 2단계] AI 공 탐지 테스트 (모터 없이 눈으로만 확인)

목표: 공을 비추면 초록 상자 + 공 이름 + 점수가 뜨면 성공!
실행 전: baseline_1이 성공했어야 합니다. best.pt 파일이 같은 폴더에 있어야 합니다.
종료: 카메라 창을 클릭하고 q 키
"""

import sys

import cv2
from ultralytics import YOLO

VIDEO_SOURCE = 1   # baseline_1에서 성공한 번호와 같게
CONF = 0.5         # 탐지 기준 점수(0~1). 공이 잘 안 잡히면 0.3으로 낮춰보세요.

print("AI 모델 로딩 중... (조금 걸려요)")
model = YOLO("best.pt")
print("이 AI가 알아보는 것들:", list(model.names.values()))

if sys.platform == "darwin":
    cap = cv2.VideoCapture(VIDEO_SOURCE, cv2.CAP_AVFOUNDATION)
else:
    cap = cv2.VideoCapture(VIDEO_SOURCE)

if not cap.isOpened():
    print("카메라를 열 수 없습니다. VIDEO_SOURCE 숫자를 확인하세요.")
    raise SystemExit

print("탐지 시작! 공을 카메라에 보여주세요. (q = 종료)")

while True:
    ok, frame = cap.read()
    if not ok:
        continue

    # AI에게 이 화면에 공이 있는지 물어본다
    r = model.predict(frame, conf=CONF, verbose=False)[0]

    # 찾은 공마다 초록 상자를 그린다
    for box in r.boxes:
        x1, y1, x2, y2 = map(int, box.xyxy[0].tolist())
        label = model.names[int(box.cls[0])]      # 공 이름 (red_normal 등)
        conf = float(box.conf[0])                 # AI의 확신 정도 (0~1)
        cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
        cv2.putText(frame, f"{label} {conf:.2f}", (x1, max(30, y1 - 10)),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)

    cv2.imshow("2. vision test (q=quit)", frame)

    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()
성공 기준 — 공을 비추면 초록 상자와 이름(red_normal 0.87 같은)이 따라다닌다.

연습 3 — 탐지 → 모터 baseline_3_motor.py

연습 2에 블루투스로 허브에 신호 보내기를 얹은 최종 코드. 실행 전에 5단계의 순서 규칙(탭 닫기 → 파란 깜빡임)을 지켜야 합니다.

baseline_3_motor.py 전체 코드 
"""
[baseline 3단계] 공 탐지 → 허브 A모터 1회전 (최종 목표!)

목표: 공을 보여주면 허브의 A모터가 한 바퀴 돌면 성공!
실행 전:
  1. baseline_2가 성공했어야 합니다.

  3. Pybricks 브라우저 탭을 완전히 닫으세요.
  4. 허브를 "파란 깜빡임" 상태로 만드세요. (초록불이면 버튼 한 번)
실행 후: 카메라 창이 뜨면 → 허브 가운데 버튼을 눌러 초록불로!
종료: 카메라 창을 클릭하고 q 키
"""

import asyncio
import sys

import cv2
from ultralytics import YOLO
from bleak import BleakScanner, BleakClient

HUB_NAME = "Pybricks Hub"   # ★ 우리 팀 허브 이름으로 바꾸세요!
VIDEO_SOURCE = 1            # baseline_1에서 성공한 번호와 같게
CONF = 0.5

# 허브와 대화하는 블루투스 주소 (Pybricks 고정값, 바꾸지 마세요)
PYBRICKS_CHAR = "c5f50002-8280-46da-89f4-6d8051e4aeef"


async def main():
    print("AI 모델 로딩 중...")
    model = YOLO("best.pt")

    print(f'허브 "{HUB_NAME}" 검색 중... (허브가 파란 깜빡임인지 확인!)')
    device = None
    while device is None:
        device = await BleakScanner.find_device_by_name(HUB_NAME, timeout=10.0)
        if device is None:
            print("  아직 못 찾음. 허브를 파란 깜빡임으로 만들면 자동 연결됩니다...")

    async with BleakClient(device) as client:
        print("허브 연결 완료! 카메라를 엽니다.")

        if sys.platform == "darwin":
            cap = cv2.VideoCapture(VIDEO_SOURCE, cv2.CAP_AVFOUNDATION)
        else:
            cap = cv2.VideoCapture(VIDEO_SOURCE)

        if not cap.isOpened():
            print("카메라를 열 수 없습니다. VIDEO_SOURCE 숫자를 확인하세요.")
            return

        seen = 0      # 공이 연속으로 보인 프레임 수
        empty = 0     # 공이 안 보인 프레임 수
        armed = True  # True일 때만 모터 신호를 보냄 (공 하나당 딱 1번)

        print(">>> 카메라 창이 뜨면 허브 가운데 버튼을 눌러 초록불로 만드세요! <<<")
        print("공을 보여주면 모터가 돕니다. (q = 종료)")

        while True:
            ok, frame = cap.read()
            if not ok:
                await asyncio.sleep(0.1)
                continue

            r = model.predict(frame, conf=CONF, verbose=False)[0]

            for box in r.boxes:
                x1, y1, x2, y2 = map(int, box.xyxy[0].tolist())
                label = model.names[int(box.cls[0])]
                cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
                cv2.putText(frame, label, (x1, max(30, y1 - 10)),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)

            # 공 감지 안정화: 3프레임 연속 보여야 진짜 공으로 인정
            if len(r.boxes) > 0:
                seen += 1
                empty = 0
            else:
                seen = 0
                empty += 1
                if empty >= 3:
                    armed = True   # 공이 사라졌으니 다음 공 받을 준비

            if armed and seen >= 3:
                print("공 감지! → 허브에 모터 1회전 신호 전송")
                # b"\x06" = "이건 명령이야" 표시, b"d" = 우리가 정한 '돌아라' 신호
                await client.write_gatt_char(PYBRICKS_CHAR, b"\x06d", response=True)
                armed = False

            cv2.imshow("3. detect -> motor (q=quit)", frame)

            if cv2.waitKey(1) & 0xFF == ord("q"):
                break

        cap.release()
        cv2.destroyAllWindows()

        print("허브에 종료 신호 전송")
        await client.write_gatt_char(PYBRICKS_CHAR, b"\x06q", response=True)


if __name__ == "__main__":
    if sys.platform == "win32":
        asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())
    asyncio.run(main())
